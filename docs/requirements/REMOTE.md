# 手机远控连接与工作区需求

本文件从原 packages/web/SPEC.md 迁移，维护 v4 连接和手机业务界面。Android 接收链接及平台行为见 [ANDROID.md](ANDROID.md)，全局范围见 [FORK.md](FORK.md)。

## 配对、桥接与状态所有权

- 本地 Web 入口校验 sid、hash、t，通过官方同源 /ws 完成 challenge 鉴权。配对成功后获取窗口 bootstrap，在可桥接工作区中选择当前项，桥接请求使用唯一 ID 与代次。
- 桥接就绪后复用现有客户端服务代理和 Root UI，可靠 RPC 帧必须保持顺序与连接代次；服务绑定当前 workspaceIdentity，UI 能读取工作区、任务并收发消息。
- 远控入口唯一持有 relay WebSocket、配对状态、工作区桥接与帧序号；页面只消费服务代理。连接服务仅在当前桥接有效时注册，断开或换代时注销，不能遗留指向旧连接的服务或让聊天永久停留在等待状态。
- 桌面 Host 是任务、会话与工作区状态的唯一所有者；手机不缓存服务端事实。配对链接与鉴权值只留在运行时内存和 Android 私有偏好中，不进入日志、构建产物或测试快照。
- 无远控参数的普通 Web 模式保持原启动路径。

## 项目列表与手机界面

- 项目列表包含 bootstrap 中全部可桥接工作区，异步到达的 recentProjects 可补充。按工作区身份和路径去重，不因不同远端路径相同而丢失项目。
- 列表注入只保证侧栏可见，不抢占当前工作区；后到的数据补入同一棵 Root，重复列表不反复改写 tab 状态，旧连接返回的结果不得写入新列表。
- “项目”全屏复用原 WorkspaceSidebar 的完整内容和操作，“聊天”复用主工作区。页签切换保留同一棵 Root 和同一条连接，不重载或重新配对。
- 点选其他可桥接项目时，按项目身份重新配对和桥接，成功后进入聊天；失败保留明确错误与重试入口。点任务进入聊天。
- 手机聊天隐藏桌面状态侧面板（Git 工具、进程、计划），会话时间线占满整宽；桌面布局不受影响。

## 中断与恢复

- 网络中断后，前台以有上限的退避延迟重新配对和桥接；后台暂停重试，返回前台立即恢复已断开的连接。手动重试可立即触发一次尝试。
- 后台停留较久时，用现有只读设置 RPC 探测看似仍打开的连接，失败或超时才替换连接。
- 无效链接、relay 明确拒绝和桥接协议错误等不可恢复错误显示原因并停止自动重试，不能无限重试。
- 每次尝试只有一个所有者；取消或断开的旧尝试不得注册服务、写项目列表或触发新连接。重连重新确认配对和桥接，旧代次响应不得交给新 UI；成功重置退避，失败保留手动重试入口。

## 验收条件与状态

1. 从真机深链进入本地页面，完成配对、工作区与任务读取、会话消息往返；后台恢复和图标冷启动重新连接可用。
2. 手机项目/聊天切换不增加配对次数，项目列表迟到不抢焦点；同路径不同远端项目都存在，选择其他可桥接项目后消息确实发往对应工作区，桥接失败可见并可重试。
3. 模拟后台停留、断网和恢复：后台无持续重连，回前台无需点击即恢复；旧连接迟到响应不能覆盖当前连接。失效配对链接显示错误且停止自动重试。
4. 手机侧栏与聊天布局符合上述要求，桌面及普通 Web 路径不回归；文件保存按 ANDROID.md 验收。
